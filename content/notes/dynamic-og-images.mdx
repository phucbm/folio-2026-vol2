Every page on this site, perxel.com and OpenRace has its own share card: a 1200×630 PNG drawn from the page's data with `next/og`. All three run on Cloudflare Workers through OpenNext, which has no filesystem, so the usual examples that read a font with `fs` break there. This note keeps only what surprised me; the step by step version is an agent skill.

## What broke

- **A `force-static` route still can't read from disk.** OpenNext can run a "static" route module again on a cache miss, so a `readFile` that works in `next build` throws in production. Perxel embeds its fonts and logos as base64 in `.ts` files. This site reads its fonts with `fs` only because a script copies every card into the static assets after the build, so the Worker never draws one.
- **Satori can't read the fonts every site ships.** No WOFF2, no variable fonts: the card needs one static TTF or WOFF per weight. Google Fonts sends WOFF if you ask with an old Safari user agent; for my own files I cut instances with fonttools.
- **WebP crashes Satori.** A hard error, not a missing image. Perxel keeps PNG copies of its tech logos just for the cards.
- **A file-based `opengraph-image` overrides `generateMetadata`.** So an entry could never have its own hand-made share image. Perxel moved its detail cards to a plain `[slug]/og/route.tsx`, and the page picks between the entry's image and the card.
- **A page's `openGraph` replaces the layout's whole object.** Not field by field. Perxel's pages had lost `og:type` and `og:site_name` before every page started spreading a shared base.

## Three ways to serve them

| | phucbm.com | perxel.com | OpenRace |
|---|---|---|---|
| Route | one `app/og/[...path]/route.tsx` | one `opengraph-image` per page, plain routes for details | one `opengraph-image` per page |
| Drawn | at build | at build | on request, with its page's `revalidate` |
| Served from | static assets, as plain files | OpenNext's cache | OpenNext's cache |
| Fonts | TTF files, read at build only | base64 in `.ts` | base64 in `.ts` |

This site and Perxel draw every card at build, because all their content is in the repo. OpenRace's races, series and organizers change all the time, so each card revalidates with its page and falls back to the page's own title when the fetch fails: a card route must always return an image.
